# CFB baseline — 2019, 2021–2025

Walk-forward evaluation on **3,256 out-of-sample FBS-vs-FBS games**. For each week
W ≥ 5, ratings and features are built from games before W only, then week W is
predicted. 2020 is excluded: the COVID schedule was not comparable.

## Headline

| Candidate | MAE (points) | vs market |
| --- | ---: | ---: |
| Closing market (consensus spread) | **12.1596** | — |
| **Ratings + opponent-adjusted efficiency** | **12.5251** | **+0.3655** |
| Ratings + raw efficiency | 12.7883 | +0.6287 |
| Ratings only | 12.9749 | +0.8154 |
| Ratings, uncapped margins | 13.4780 | +1.3184 |

**The model still does not beat the market**, but it no longer loses
confidently. ATS on the games where the model disagrees with the spread:

| | opponent-adjusted | raw (superseded) |
| --- | --- | --- |
| Record | 1651–1579–26 | 1593–1637–26 |
| Win rate | **51.11%** | 49.32% |
| 95% CI | **[49.39%, 52.84%]** | [47.59%, 51.04%] |
| Breakeven at −110 | 52.38% | 52.38% |

The raw-stat interval sat entirely below breakeven — confidently unprofitable.
The opponent-adjusted interval **straddles** it. That is a change in kind: the
model is now *indistinguishable* from breakeven rather than losing. It is still
not evidence of an edge — the point estimate is 51.11% against a 52.38% bar, and
an interval containing the bar is exactly what "unproven" looks like. Authority
stays `RESEARCH_ONLY`; see `src/cfbmodel/authority.py`.

## Opponent adjustment (step 1)

Raw season efficiency is confounded by schedule. Adjusting jointly, the same way
the power ratings are solved:

| Feature set | MAE |
| --- | ---: |
| Raw season stats, all plays | 12.8297 |
| Raw season stats, garbage time excluded | 12.8229 |
| **Opponent-adjusted, garbage time excluded** | **12.5251** |

Worth 0.30 points overall. Garbage-time exclusion *alone* is worth 0.007 —
margin capping in `ratings.py` already blunts blowouts upstream — but it is kept
on because it is free and adjusts the right quantity.

The gain lands where the diagnostic said the model was weakest:

| Weeks | MAE before | MAE after |
| --- | ---: | ---: |
| 5–7 | 13.369 | **12.668** |
| 8–10 | 12.875 | 12.547 |
| 11–13 | 12.712 | 12.350 |

Prediction SD rose from 11.44 to 12.16 against the market's 12.67 and an actual
19.90, so the model is also less under-dispersed than it was.

Season-only stats (`pointsPerOpportunity`, `havoc`) added on top of the adjusted
set changed MAE by 0.0001 and were dropped.

## What the blowout cap is worth

36% of FBS games are decided by 28+ points (the NFL figure is nearer 8%), so an
unadjusted mean margin lets garbage time drive the ratings.

| cap | MAE | | cap | MAE |
| ---: | ---: | --- | ---: | ---: |
| none | 13.4780 | | 32 | **12.9913** |
| 42 | 13.0190 | | 28 | 13.0090 |
| 40 | 13.0097 | | 24 | 13.0670 |
| 38 | 13.0010 | | 21 | 13.1390 |
| 35 | 12.9915 | | 17 | 13.3000 |
|  |  | | 14 | 13.4870 |

Capping is worth ~0.49 points of MAE, and the optimum is broad and flat between
28 and 42. The cap is smooth — `cap · tanh(margin / cap)` — so ordering survives
above the threshold instead of every blowout collapsing to one value.

Recency (half-life 12 weeks) and shrinkage were tuned the same way but move MAE
only from 12.9913 to 12.9749. **Treat cap as the real parameter and the other two
as marginal**; they may not survive out of this sample.

## A hypothesis the data rejected

Ratings are solved on *capped* margins, so a rating gap lives in capped space and
should arguably be expanded back through the inverse transform before projecting.
Tested directly:

| expansion α | MAE |
| ---: | ---: |
| 0.00 (none) | **12.9749** |
| 0.25 | 13.0620 |
| 0.50 | 13.2485 |
| 1.00 | 13.6962 |

Expansion is monotonically worse. The compressed scale is better calibrated for
competitive games, so no expansion is applied.

## Matrix weights, and the explosiveness story

Weights are standardised importances (|coefficient| × feature SD) from a
leave-one-season-out fit, normalised within each group.

| Offense | weight | | Defense | weight |
| --- | ---: | --- | --- | ---: |
| success_rate | 0.5796 | | success_rate_allowed_inv | 0.5402 |
| explosiveness | 0.1533 | | explosiveness_allowed_inv | 0.1889 |
| ppa_per_play | 0.1488 | | ppa_allowed_inv | 0.1451 |
| stuff_rate_inverse | 0.1183 | | stuff_rate | 0.1258 |

**Explosiveness was measured wrong twice before it was measured right.** The
original scaffold reasoned that weaker, more variable CFB defenses make big plays
more repeatable, so explosiveness deserved more weight than the NFL's 0.14.
Fitted on *raw* season stats it scored **0.016** and looked worthless, and that
was written up as the prior being refuted. Fitted on *opponent-adjusted* stats it
scores **0.153** on offense and **0.189** on defense.

The prior was right. The raw measurement was confounded by schedule strength — a
team piling up explosive plays against weak defenses looks explosive and is not,
and averaging that noise across a season buried the real signal. Success rate
still dominates both sides.

Fitted coefficients (full sample, margin in points, opponent-adjusted features):

```
intercept        +0.5920      def_ppa           -6.2664
rating_margin    +0.4476      def_successRate  -49.7084
off_ppa          +5.5250      def_explosiveness -6.6809
off_successRate +47.1558      def_stuffRate    +12.3940
off_explosiveness +5.4551
off_stuffRate   -12.0629
```

The rating term drops from +0.8076 to +0.4476 because opponent-adjusted
efficiency now carries much of what the ratings were carrying alone.

Collapsing the eight features into two weighted indices costs 0.0745 MAE (12.5995
vs 12.5251) and drops ATS to 50.34%, so **the forecast uses the full fit and the
weights document it**. The matrix is the interpretation, not the predictor.

## Preseason priors (step 2)

Weeks 1-4 previously ran on the prior season's ratings scaled by a flat 0.72.
Replaced with a fitted preseason rating from prior seasons, recruiting talent,
returning production, and recruiting class points.

Predicting a team's eventual end-of-season rating (MAE in rating points, 788
team-seasons, leave-one-season-out):

| Prior | MAE |
| --- | ---: |
| carryover 0.72 × prior season | 5.5966 |
| prior rating only | 5.6046 |
| + two seasons back | 5.4535 |
| + talent composite | 5.3281 |
| + returning production | 5.3149 |
| **+ recruiting points** | **5.1202** |

On actual weeks 1-4 margins, blending that prior with results as they arrive
(0.14 of the current season folded in per completed week):

| Method | MAE |
| --- | ---: |
| carryover 0.72 (previous) | 14.2446 |
| preseason prior, no blending | 14.1585 |
| **preseason + in-season blend** | **13.7945** |
| Market, same games | 12.0043 |

Worth 0.45 points, and 1.0 in week 1 specifically. **It does not make weeks 1-4
trustworthy**: the gap to the market there is still +1.79 against +0.37 from week
5 on, so `FIRST_VALIDATED_WEEK` stays at 5 and the board keeps its warning — now
quoting the real numbers rather than describing a carryover that no longer exists.

### Week 1 scale audit

Week 1 is a separate regime: no current-season observations and a much larger
share of extreme talent mismatches. On 282 FBS-vs-FBS games from 2019 and
2021–2025, holding out one entire season at a time:

| Candidate | MAE | Market-underdog side rate |
| --- | ---: | ---: |
| Raw preseason margin | 14.4109 | 86.8% |
| **Affine-calibrated margin** | **12.8499** | **60.5%** |
| Nonlinear tail expansion | 12.8854 | 61.6% |
| Market | **11.7838** | — |

The affine fold slopes ranged from 1.4490 to 1.6045, with pooled slope 1.5333
(fold SD 0.0466) and intercept 1.7236 (fold SD 0.2482). That stability and the
1.56-point held-out MAE improvement justify applying it to Week 1 only. It does
not justify calling the remaining market gap an edge: ATS on the calibrated
side was 136–144–1, and the market remained 1.07 points better in MAE.

The reproducible candidate and spread-bucket audit is
`scripts/audit_week1_bias.py`.

## Totals and projected scores

Margin uses feature differences; a total uses sums plus pace (drives and plays
per game). Same 3,256-game walk-forward, leave-one-season-out:

| Candidate | MAE |
| --- | ---: |
| League-mean total | 13.6544 |
| **Model total** | **13.0446** |
| Market total | 12.5055 |

Over/under where the model disagrees with the market total: **1660–1567–29 =
51.44%**, 95% CI [49.72%, 53.17%], breakeven 52.38% — the same standing as the
spread side, and not a betting signal.

Totals are genuinely hard here: the residual SD is **16.36** against an actual
total SD of 17.14, so the model explains only a small share of the variance.
Worth stating plainly, because a projected scoreline reads as far more precise
than it is.

Projected scores are algebra on the two projections:

```
home = (total + margin) / 2
away = (total - margin) / 2
```

They inherit the error of *both* models. The board builds the scoreline from the
**model** margin rather than the published one — at lam = 0 the published margin
is the market, so a "projected score" built on it would be the market's
projection wearing the model's label.

Fitted coefficients:

```
intercept              -72.2106     def_ppa_sum            +11.8368
off_ppa_sum             +8.0872     def_successRate_sum    +35.1964
off_successRate_sum    +31.4456     def_explosiveness_sum   +3.6070
off_explosiveness_sum   +9.7213     def_stuffRate_sum      +11.1479
off_stuffRate_sum       +2.0282     drives_sum              +0.1734
                                    plays_sum               +0.1688
```

## Talent reconstruction

CFBD publishes a team talent composite through 2025 but **not 2026** — the
endpoint returns zero rows — so the preseason model's talent term was silently
zero for every team, which reads as parity rather than as a missing feed.

Roster talent is accumulated recruiting, so it is rebuilt from the last four
recruiting classes. Fitted on 1,088 team-years (2019–2025), validated
leave-one-year-out:

| | |
| --- | --- |
| Correlation with published talent | **0.9350** |
| R² | 0.8741 |
| MAE | 64.71 (talent SD 260.08) |
| Beats current-class-only baseline | 0.9350 vs 0.9149 |

Per-season correlation runs 0.90–0.98. The effect on the model, measured on
weeks 1–4 where the preseason prior does the work:

| Talent source | Weeks 1–4 MAE |
| --- | ---: |
| Published (2019–2025) | 13.7945 |
| **Reconstructed** | **13.7834** |
| None — the 2026 status quo | 13.9000 |

Reconstruction is *marginally better* than the published composite, so it is a
safe substitute rather than a degradation, and it recovers 0.117 points that
2026 was otherwise giving up. Published data is still preferred whenever CFBD
has it; the breakdown labels which source produced the number.

## Scope — where this is *not* validated

Everything above is weeks 5+, FBS-vs-FBS. Weeks 1–4 have no current-season form
and lean on discounted carryover, and week-1 slates are full of
power-conference-vs-Group-of-5 mismatches that barely occur later. On the 2026
week 1 slate the model read Indiana −14.1 against a market of −40.8. **The market
was right.** `forecast.FIRST_VALIDATED_WEEK` flags this and the board prints a
warning rather than presenting those numbers as comparable.

## Calibration, and why the board stopped publishing a preseason edge

Added 2026-08-27, after a standing complaint that the model leaned to underdogs
whenever the market was wide. It did, and the cause is not an opinion.

### The measurement

On the 2026 week-1 board (49 FBS-vs-FBS games carrying both a model margin and a
market margin), regressing the model on the market:

| | value |
| --- | ---: |
| slope (model ~ market) | **0.478** |
| SD(model) | 8.05 |
| SD(market) | 15.18 |
| games on the market underdog | **43 of 49** |
| games on the underdog where \|spread\| > 7 | **37 of 37** |

Mean miss on the favourite's number, by price:

| \|spread\| | n | mean(model − market) |
| ---: | ---: | ---: |
| 0–7 | 12 | −1.10 |
| 7–14 | 9 | −6.19 |
| 14–21 | 5 | −8.96 |
| 21+ | 23 | −15.63 |

### It is confined to the preseason path

Against this section's own walk-forward dispersion numbers:

| regime | model SD | market SD | ratio |
| --- | ---: | ---: | ---: |
| weeks 5+ (validated) | 12.16 | 12.67 | **0.96** |
| week 1 (ratings-only) | 8.05 | 15.18 | **0.53** |

The full-regime path is fine. `intercept + 0.4476 · base + efficiency` is an OLS
fit and is scale-calibrated by construction; the low rating coefficient is not
shrinkage, efficiency carries the rest.

The preseason path is not. `preseason.COEFFICIENTS` carries `prior_rating`
0.392005 + `prior_rating_2` 0.153911 = **0.546** on the rating scale, fitted to
predict a team's own end-of-season rating. That is the right estimator for that
target and a shrunk one for this one: differencing two shrunk ratings gives a
compressed gap, and `forecast._model_margin`'s fallback then reads it back at an
implicit slope of 1.0 with only a constant correction (−2.1204). The constant
fixes the mean. Nothing fixed the scale.

### What is left after rescaling

Rescaling by the fitted 1.699 (regressing market on rating gap: R² 0.812,
r 0.901) removes **78%** of the error on wide prices — mean miss on \|spread\| ≥ 21
goes from −12.44 to −2.73. Residual SD is 6.58 points, and it is not noise:

| bucket | n | mean residual, oriented to the favourite |
| --- | ---: | ---: |
| P4 vs P4 | 11 | −1.77 |
| P4 vs G5 | 28 | **−3.29** |
| G5 vs G5 | 10 | **+3.55** |

A ~6.8-point tier gap that survives rescaling. Four mechanisms, all in the code:
all FCS opponents share one pooled `__FCS__` rating so G5 schedule-padding
flatters weak teams; the cap bites hardest on exactly the cross-tier blowouts
that define the tier gap (63% of a 45-point margin retained, against 94% of a
14-point one); cross-tier scheduling is sparse so the two sub-graphs are weakly
connected in the iterative solve; and there is no conference or tier term in
`preseason.COEFFICIENTS` at all.

### The decision

**No expansion was adopted.** Two reasons, and the first is already in this
report: expansion was tested and is monotonically worse on MAE (12.9749 → 13.6962).
The second is that the market is itself under-dispersed against actual outcomes
(SD 12.67 vs 19.90) — under-dispersion is what a conditional mean does, and it
is *correct* to shrink harder when conditioning on less. The preseason path
conditions on far less than the price does: no transfer portal (`portal_net_rating`
is declared in `matrix.TALENT_WEIGHTS` and **never fetched or fitted**), no
quarterback-specific returning production, no coaching change, no availability.

Inflating the estimate to match a better-informed one manufactures confidence the
model has not earned. So instead:

1. `forecast.Forecast` gained `market_gap` (always published) and now returns
   `edge_points = None` outside the validated regime, with `edge_withheld_reason`
   saying which rule fired. The difference stays visible; it stops being called
   an edge.
2. `calibration.py` measures the slope MAE cannot see. `cfbmodel calibrate`
   fits it per regime against actual outcomes.
3. `calibration.PRESEASON` ships as identity. Adopting a fitted correction is a
   claim about evidence and belongs in a commit with the numbers beside it.

Open, in priority order: a tier/conference term and FCS stratification (worth the
6.8-point bucket gap, and improves MAE *and* calibration rather than trading
one for the other); wiring the portal; separating quarterback returning
production from the blend.

## Correction: the compression finding did not survive a larger sample

The section above measured a model-on-market regression slope of 0.478 on a
single 2026 week-1 board (n=49) and concluded the preseason estimate was
compressed by roughly half. Measured against **actual outcomes** on 1,015
completed preseason-path games (2021–2025, weeks 1–6) with the refitted
coefficients, that is wrong:

| regime | n | calibration slope (actual ~ model) | dispersion vs market | model MAE | market MAE |
| --- | ---: | ---: | ---: | ---: | ---: |
| preseason path | 1,015 | **1.020** | 0.807 | 13.9129 | 12.0770 |
| validated (wk 5+) | 533 | **0.926** | 0.950 | 12.0259 | 11.4878 |

Both slopes sit on 1.0. **The model is correctly scaled in both regimes.** Week
1 is the most buy-game-heavy week of the season and 49 games was far too small a
sample to establish a scale claim; the 0.478 was noise plus selection, not a
property of the estimator.

What is real is the **information gap**: +1.84 points of MAE against the market
on the preseason path, +0.54 in the validated regime, with dispersion at 0.81
and 0.95 of the market's. Both estimators are calibrated; the market conditions
on more. That is the gap `docs/DATA_SOURCES.md` inventories, and it is not
closeable by rescaling anything.

The practical consequence is unchanged — `edge_points` stays withheld outside
the validated regime — but the *reason* is now the measured MAE gap rather than
a compression that does not exist.

## Preseason refit, 2026-08-27

658 team-seasons (2021–2025), leave-one-season-out, target = end-of-season
rating. Run with `cli fit-preseason`.

| candidate | MAE | vs shipped |
| --- | ---: | ---: |
| carryover only | 5.5369 | +0.4314 |
| current (shipped) | 5.1055 | — |
| + qb & portal | 5.1184 | +0.0129 |
| + coaching | 5.0729 | −0.0326 |
| **+ coaching (stable only)** | **5.0526** | **−0.0529** |

`coach_shift_explosiveness` and `coach_tenure` were dropped automatically: their
fold-to-fold SD exceeded the magnitude of their own mean, so they changed sign
between folds. The prune re-runs on every fit.

Adopted into `preseason.EXTRA_COEFFICIENTS`. The headline term is
`first_year_coach` at **−2.649 ± 0.422** — a new head coach costs about two and
a half rating points, and it is the one fact here the ratings provably cannot
infer, because a coaching change leaves no trace in last season's margins.
`portal_net` (+0.091 ± 0.015) and `portal_churn` (+0.033 ± 0.007) are also
stable. `qb_returning` (+0.128 ± 0.108) is marginal and survives the prune only
narrowly.

Note the gain is ~1% of preseason rating MAE. It is a real improvement and it is
not close to closing the 1.84-point margin gap to the market.

**A bug this refit surfaced.** `/coaches?year=N` filters each coach's nested
`seasons` list to that single year, so the first attempt scored every coach in
the league as a first-year hire with no record, and no philosophy profile could
be built at all. `cfbd.coaches(season, history=n)` uses `minYear`/`maxYear`
instead. Against real data 28% of 2024 head coaches were first-year, which is
the plausible figure.
